# Lottery Report

แอป Android สำหรับติดตามกำหนดวันออกรางวัลและผลสลากกินแบ่งรัฐบาล

## สถานะปัจจุบัน

เริ่มต้นโครงการแล้ว ส่วนติดต่อผู้ใช้ระยะแรกเป็นโครงหน้าจอ (UI skeleton) และยัง **ไม่ได้เชื่อมต่อแหล่งข้อมูล GLO** ข้อมูลตัวอย่างหรือสถานะที่ยังไม่มีข้อมูลจริงจะต้องไม่ถูกแสดงเป็นข้อมูลทางการ

## ขอบเขต

- แสดงกำหนดวันออกรางวัล โดยแยกวันที่ยืนยันจากวันที่ประมาณการ
- ตรวจจับประกาศเปลี่ยนแปลงกำหนดการจากแหล่งข้อมูลที่ตรวจสอบย้อนกลับได้
- ดึงและตรวจสอบผลรางวัลหลังเผยแพร่จากแหล่งข้อมูลทางการ
- เก็บประวัติที่ตรวจสอบแล้วไว้ในเครื่องและค้นหาได้
- แจ้งเตือนตามการตั้งค่าของผู้ใช้ โดยป้องกันการแจ้งซ้ำ
- รองรับการใช้งานออฟไลน์ด้วยข้อมูลล่าสุดที่ตรวจสอบแล้ว
- ใช้เวลาไทย (Asia/Bangkok) และภาษาไทย

## แนวทางทางเทคนิค

Kotlin, Jetpack Compose, Material 3, Room, Coroutines, WorkManager และสถาปัตยกรรม MVVM/Repository โดยยึดแนวทาง local-first

## ความถูกต้องและความปลอดภัย

- ไม่ถือว่าข้อมูลจาก mock หรือ response ที่ไม่สมบูรณ์เป็นผลรางวัลจริง
- ไม่เขียนทับข้อมูลที่ตรวจสอบแล้วเมื่อการเชื่อมต่อล้มเหลวหรือข้อมูลใหม่ผิดรูปแบบ
- แยกการตรวจสอบกำหนดวันออกรางวัลออกจากการตรวจสอบผลรางวัล
- ไม่ฝัง API keys หรือ secrets ในแอป
- ใช้ HTTPS และระบุแหล่งที่มาของข้อมูลทุกครั้งที่เชื่อมต่อ
- แอปนี้ไม่ใช่แอปอย่างเป็นทางการของสำนักงานสลากกินแบ่งรัฐบาล (GLO)

## แผนพัฒนา

1. วางโครงสร้างโปรเจกต์และหน้าจอภาษาไทย
2. เพิ่มฐานข้อมูลภายในและโมเดลข้อมูล
3. เพิ่มแหล่งข้อมูลกำหนดการที่เป็นทางการและตรวจสอบได้
4. เพิ่มแหล่งข้อมูลผลรางวัลและชุดทดสอบความถูกต้อง
5. เพิ่มการแจ้งเตือนและทดสอบการทำงานออฟไลน์
6. Build และตรวจสอบ APK ผ่าน GitHub Actions
