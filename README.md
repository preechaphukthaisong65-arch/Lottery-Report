# Lottery Report

แอป Android ภาษาไทยสำหรับติดตามกำหนดวันออกรางวัลและผลสลากกินแบ่งรัฐบาล โดยยึดข้อมูลที่ตรวจสอบแหล่งที่มาได้

## สถานะการพัฒนา

โปรเจกต์อยู่ระหว่างพัฒนา ยังไม่ใช่แอปพร้อมใช้งานจริง และยังไม่ควรใช้เป็นแหล่งอ้างอิงผลรางวัล

- หน้าจอหลัก 4 ส่วน: ภาพรวม, ปฏิทิน, ผลรางวัล, ตั้งค่า
- มีโครงสร้าง Room สำหรับจัดเก็บผลรางวัลและกำหนดการแยกตาราง
- มี Repository ที่ตรวจสอบรูปแบบข้อมูลและแหล่ง HTTPS ของโดเมน GLO ก่อนบันทึก
- มี migration แบบไม่ลบข้อมูลเดิม
- มี unit tests สำหรับตรวจสอบรูปแบบชุดผลรางวัลหลัก
- ยังไม่ได้เชื่อมต่อ API จริงของ GLO
- ยังไม่มีระบบแจ้งเตือน/ซิงก์อัตโนมัติที่เปิดใช้งาน
- ยังไม่มี Release signing key หรือ APK Release ที่ลงลายเซ็น

## แหล่งข้อมูลและข้อจำกัด

ดูรายละเอียดใน docs/DATA_SOURCES.md

GLO เผยแพร่ข้อมูลผลรางวัลผ่าน Data Catalog และมีหน้าให้ตรวจผลรางวัลทางการ อย่างไรก็ตาม API endpoint และรูปแบบ response ต้องตรวจสอบจากเอกสาร/การอนุญาตของ GLO ก่อนนำมาเชื่อมจริง

หน้า Data Catalog ระบุสัญญาอนุญาต Creative Commons Non-Commercial (Any) จึงต้องตรวจสอบเงื่อนไขก่อนนำข้อมูลไปใช้ในผลิตภัณฑ์เชิงพาณิชย์หรือเปิดหารายได้

## สถาปัตยกรรม

- Kotlin + Jetpack Compose + Material 3
- MVVM/Repository direction
- Room local database
- Kotlin Coroutines / Flow
- Retrofit/OkHttp dependencies เตรียมไว้สำหรับ adapter หลังยืนยัน API
- WorkManager dependency เตรียมไว้สำหรับงานเบื้องหลัง
- เวลาอ้างอิง: Asia/Bangkok
- applicationId: th.co.lotteryreport
- versionCode: 1, versionName: 0.1.0

## ความปลอดภัยและความถูกต้อง

- ไม่ฝัง API keys, passwords หรือ signing keys ใน source code
- ไม่แทนที่ข้อมูลผลรางวัลเดิมด้วย response ว่างหรือผิดรูปแบบ
- ป้องกันการบันทึกซ้ำด้วย unique index
- แยกตารางกำหนดการออกจากผลรางวัล
- วันประมาณการต้องไม่ทับวันยืนยันทางการ
- การตรวจสอบโครงสร้างข้อมูลไม่ใช่หลักฐานยืนยันความถูกต้องของผลรางวัล
- แอปนี้เป็นแอปอิสระ ไม่ใช่แอปอย่างเป็นทางการของสำนักงานสลากกินแบ่งรัฐบาล

## CI

GitHub Actions รัน unit tests และสร้าง Debug APK สำหรับทดสอบ โดยต้องตรวจผล workflow ล่าสุดก่อนถือว่า build ผ่าน

Release APK จะเปิดใช้งานหลังจากเจ้าของโปรเจกต์สร้างและสำรอง Android Keystore พร้อมตั้งค่า GitHub Actions Secrets อย่างปลอดภัยเท่านั้น
