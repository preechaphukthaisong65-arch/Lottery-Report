# Lottery Report

แอป Android ภาษาไทยสำหรับติดตามกำหนดวันออกรางวัลและผลสลากกินแบ่งรัฐบาล โดยยึดข้อมูลที่ตรวจสอบแหล่งที่มาได้

## สถานะการพัฒนา

โปรเจกต์อยู่ระหว่างพัฒนา ยังไม่ใช่แอปพร้อมใช้งานจริง และยังไม่ควรใช้เป็นแหล่งอ้างอิงผลรางวัล

- หน้าจอหลัก 4 ส่วน: ภาพรวม, ปฏิทิน, ผลรางวัล, ตั้งค่า
- มี Room สำหรับจัดเก็บผลรางวัลและกำหนดการแยกตาราง
- มี Repository ตรวจสอบรูปแบบข้อมูลและแหล่ง HTTPS ของโดเมน GLO ก่อนบันทึก
- มี migration แบบไม่ลบข้อมูลเดิม และ unit tests สำหรับตรรกะสำคัญ
- สร้างวันปกติวันที่ 1 และ 16 ล่วงหน้า 12 เดือนเป็น ESTIMATED เท่านั้น
- มีลิงก์เปิดหน้า FAQ และหน้าตรวจผลรางวัลทางการของ GLO
- ยังไม่ได้เชื่อมต่อ API อัตโนมัติของ GLO
- ยังไม่มีระบบแจ้งเตือนหรือซิงก์อัตโนมัติที่เปิดใช้งาน
- Release 0.1.0 เคยสร้างแบบ signed และติดตั้งทดสอบแล้ว; Release 0.2.0 ยังไม่ถูกสร้าง

## แหล่งข้อมูลและข้อจำกัด

ดูรายละเอียดใน [docs/DATA_SOURCES.md](docs/DATA_SOURCES.md)

GLO Data Catalog แสดงรายการ API Resource สำหรับผลรางวัลล่าสุดและการค้นหาตามวันที่ แต่หน้าเอกสารที่ตรวจสอบได้ยังไม่เปิดเผย Endpoint และ Response Schema ที่เพียงพอให้ยืนยันการเชื่อมต่ออัตโนมัติได้ จึงยังไม่ฝัง API ที่คาดเดาเอง

ชุดข้อมูลระบุสัญญาอนุญาต Creative Commons Non-Commercial (Any) แอปนี้กำหนดเป้าหมายใช้งานส่วนตัว ไม่มีโฆษณาและไม่มีการขาย แต่ยังต้องปฏิบัติตามเงื่อนไขของแหล่งข้อมูล

## สถาปัตยกรรม

- Kotlin + Jetpack Compose + Material 3
- MVVM/Repository direction
- Room local database
- Kotlin Coroutines / Flow
- Retrofit/OkHttp dependencies เตรียมไว้สำหรับ adapter หลังยืนยัน API
- WorkManager dependency เตรียมไว้สำหรับงานเบื้องหลัง
- เวลาอ้างอิง: Asia/Bangkok
- applicationId: th.co.lotteryreport
- versionCode: 1, versionName: 0.1.0

## ความปลอดภัยและความถูกต้อง

- ไม่เก็บ API keys, passwords หรือ signing keys ใน source code
- ไม่แทนที่ข้อมูลผลรางวัลเดิมด้วย response ว่างหรือผิดรูปแบบ
- ป้องกันการบันทึกซ้ำด้วย unique index
- แยกตารางกำหนดการออกจากผลรางวัล
- วันประมาณการต้องไม่ทับวันยืนยันทางการ
- การตรวจสอบโครงสร้างข้อมูลไม่ใช่หลักฐานยืนยันความถูกต้องของผลรางวัล
- แอปนี้เป็นแอปอิสระ ไม่ใช่แอปอย่างเป็นทางการของสำนักงานสลากกินแบ่งรัฐบาล

## CI และ Release

GitHub Actions รัน unit tests และสร้าง Debug APK เมื่อ Push ไปยัง main

Signed Release ใช้ Keystore ที่เจ้าของโปรเจกต์จัดเตรียมผ่าน GitHub Actions Secrets เท่านั้น ห้ามใส่ Keystore หรือรหัสผ่านลงใน repository การสร้าง Release ทำผ่าน workflow_dispatch หลังเพิ่ม versionCode/versionName และตรวจ migration แล้ว
